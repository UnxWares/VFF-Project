Material
Object

Une série de matériel roulant ayant circulé en France : locomotives (vapeur, diesel, électriques), automotrices, autorails, rames TGV, voitures, wagons, tramways, engins de service.

Fiches importées de Wikidata (CC0, aucune obligation) ; image et droits lus dans Wikimedia Commons (licence propre à chaque fichier, à afficher avec l'image). Un champ nul veut dire que la source ne le renseigne pas : VFF n'estime aucune valeur. La provenance de chaque champ est dans field_sources.

Fields

#

id
ID !
Non-null

Identifiant interne du matériel.

slug
String !
Non-null

Identifiant stable et lisible, dérivé du nom (ex. bb-15000), utilisé dans les URL du site et de l'API REST.

name
String !
Non-null

Nom d'usage de la série : titre de l'article Wikipédia en français, sinon libellé Wikidata (ex. « BB 15000 »).

type
String !
Non-null

Catégorie : locomotive_vapeur, locomotive_diesel, locomotive_electrique, automotrice (rame automotrice électrique), bimode (engin qui circule sous caténaire et à l'énergie thermique : Régiolis, AGC bimodes ; rangé là seulement quand Wikidata ou l'infobox de l'article Wikipédia le dit, sinon l'engin reste automotrice ou autorail), autorail (rame thermique), rame_tgv (grande vitesse), voiture (voiture voyageurs), wagon (marchandises), tramway, engin_service (engin de l'infrastructure : auscultation, chasse-neige, draisine).

type_label
String !
Non-null

Libellé français de la catégorie (ex. « Locomotive électrique »).

designations
[String !]!
Non-null

Autres noms : libellés et alias Wikidata (français, anglais), surnoms. Liste vide si aucun.

description
String

Courte description en français (description Wikidata, CC0), ex. « série de 65 locomotives électriques de la SNCF ».

builder
String

Constructeurs en une ligne lisible, noms séparés par des virgules (ex. « Alstom, Matériel de Traction Électrique »).

builders
[MaterialBuilder !]!
Non-null

Constructeurs, un par entrée, avec le nombre d'engins construits par chacun quand il est connu.

operators
[MaterialOperator !]!
Non-null

Exploitants de la série, avec leur période d'exploitation et le nombre d'engins quand ils sont connus.

in_service_from
Int

Année de mise en service de la série (la plus ancienne déclarée). Nulle si inconnue.

in_service_to
Int

Année de retrait du service (la plus récente déclarée). Nulle si la série circule encore OU si la date de retrait n'est pas renseignée : ne concluez pas qu'elle est en service (voir service pour l'état d'utilisation, quand une source le dit).

service
MaterialService !
Non-null

État d'utilisation, seulement quand une source le dit (Wikidata P5817, effectif de l'infobox Wikipédia) ; tous les champs sont nuls sinon.

scope
String !
Non-null

Périmètre de la fiche : france (série rattachée à la France dans Wikidata) ou attested (série non rattachée, par exemple un ICE, un AVE ou une locomotive belge, ajoutée parce qu'une source atteste sa circulation sur une ligne française : voir field_sources (champ scope) et line_links).

units_built
Int

Nombre d'engins construits, s'il est univoque dans la source.

max_speed_kmh
Int

Vitesse maximale en km/h (la plus grande déclarée, convertie si la source l'exprime en mi/h).

power_kw
Int

Puissance nominale en kilowatts (la plus grande déclarée ; convertie depuis les chevaux-vapeur métriques si besoin, valeur d'origine dans field_sources). Rarement renseignée.

electrification
[MaterialElectrification !]!
Non-null

Alimentations électriques (ex. « électrification ferroviaire 25 kV 50 Hz »). Liste vide pour un engin thermique ou si non renseignée.

gauge_mm
Int

Écartement en millimètres quand la série n'en a qu'un (1435 voie normale, 1000 voie métrique). Nul si inconnu ou multiple.

gauges
[MaterialGauge !]!
Non-null

Écartements de la série.

wheel_arrangement
String

Disposition des essieux telle que libellée par Wikidata (ex. « B'B' », « 141 »).

fleet_numbers
String

Numéros des engins de la série, tels que déclarés (ex. « 15001 - 15065 » ; plusieurs plages séparées par « ; »).

image
MaterialImage

Image principale, hébergée par Wikimedia Commons, avec ses droits. Nulle si aucune.

Adresse de la catégorie Commons.

String

Élément Wikidata de la série (ex. Q746572). Nul pour une fiche saisie dans VFF.

String

Adresse de l'élément Wikidata.

Titre de l'article Wikipédia en français.

wikipedia_fr_url
String

Adresse de l'article Wikipédia en français.

wikipedia_en
String

Titre de l'article Wikipédia en anglais.

wikipedia_en_url
String

Adresse de l'article Wikipédia en anglais.

lines_count
Int !
Non-null

Nombre de lignes de VFF que la série a parcourues d'après une source (voir line_links).

source
String

Provenance de la fiche : wikidata, ou nulle pour une fiche saisie dans VFF.

Provenance !
Non-null

Fournisseur de la fiche et sa licence (Wikidata : CC0). L'image a sa propre licence (image).

Provenance de chaque champ renseigné : source, référence précise, adresse, licence.

Lignes sur lesquelles ce matériel a circulé ou circule (sans la preuve : voir line_links).
