LineEvent
Object

Un événement daté de la vie d'une ligne : ouverture, fermeture, électrification, dépose…

La date est exacte au jour près quand on la connaît : lisez event_date avec date_precision pour n'afficher que la partie connue (jj/mm/aaaa, mm/aaaa ou aaaa).

Fields

#

id

ID !
Non-null

Identifiant interne de l'événement.

type

String !
Non-null

Nature de l'événement.

  • Trafic, tous services : opening (ouverture), closure (fermeture), reopening (réouverture).
  • Un seul service : opening_passenger, closure_passenger, reopening_passenger (voyageurs) ; opening_freight, closure_freight, reopening_freight (fret). Une ligne fermée aux voyageurs mais ouverte au fret devient une ligne fret.
  • Infrastructure : electrification, modernization (modernisation), dismantling (dépose de la voie), conversion (reconversion de l'emprise en voie verte, route… ; voie déposée).
  • Administration : concession, concession_end (fin de concession), declassification (retrait juridique du réseau, qui ne prouve pas la dépose).
  • Associations : heritage_start, heritage_end (train touristique, vélorail, musée).
  • Autres : accident, other.

event_date

Date !
Non-null

Date de l'événement (AAAA-MM-JJ), à lire avec date_precision.

date_precision

String

Précision de event_date : day (date exacte, à afficher jj/mm/aaaa), month (mois et année connus, jour fixé à 01), year (année seule, mois et jour fixés à 01). Nul : day.

section_from

String

Début de la portion concernée (gare ou lieu), si l'événement ne touche qu'une section de la ligne.

section_to

String

Fin de la portion concernée (gare ou lieu).

description

String

Description de l'événement, en français.

source

String

Provenance de l'information : wikipedia, wikipedia-reseaux, wikidata, ohm (OpenHistoricalMap), lignes-oubliees, archeoferroviaire, osm, heritage, estimation-reseau (date déduite du réseau voisin), manual (saisie VFF)…

source_url

String

Lien vers le document source consulté. Citez-le en réutilisant la donnée.

line

Line !
Non-null

La ligne concernée.
