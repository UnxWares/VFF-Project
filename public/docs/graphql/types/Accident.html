Accident
Object

Un accident ou un événement grave du rail français : date et précision, nature, lieu, lignes rattachées, bilan humain et sa source, résumé, sources ouvertes avec leur licence.

Faits recoupés entre Wikidata (CC0), Wikipédia (faits seulement, CC BY-SA 4.0 pour toute citation) et le bilan général des enquêtes du BEA-TT (Licence Ouverte 2.0), par vff:import-accidents. Un champ nul veut dire qu'aucune source consultée ne le donne : VFF n'estime aucune valeur. Aucune victime n'est nommée.

Fields

#

id
ID!
Non-null

Identifiant interne de l'accident.

slug
String!
Non-null

Identifiant stable et lisible : date (selon sa précision) puis commune (ex. 2013-07-12-bretigny-sur-orge).

wikidata_id
String

Élément Wikidata (Q…), nul si l'accident n'y figure pas (accident connu par le seul BEA-TT).

name
String!
Non-null

Nom usuel : libellé Wikidata, sinon nom construit par VFF (nature et commune).

kind
String!
Non-null

Nature : collision (entre trains ou avec un obstacle sur la voie), derailment (déraillement), level_crossing (collision à un passage à niveau), fire (incendie), explosion, structure_failure (rupture d'ouvrage : pont, tunnel, mur, rail), attack (attentat), person_struck (personnes heurtées hors passage à niveau), runaway (dérive), incident (incident grave sans accident : quasi-collision, dépassement de vitesse, immobilisation), other.

date
Date!
Non-null

Date de l'accident (AAAA-MM-JJ), à lire avec date_precision (au 1er du mois ou au 1er janvier si moins précise).

date_precision
String!
Non-null

Précision de date : day (date exacte), month (mois et année), year (année seule).

time
String

Heure locale (HH:MM) quand une source la donne.

commune
String

Commune actuelle (contours IGN ADMIN EXPRESS) où se trouve le lieu.

commune_insee
String

Code INSEE de la commune.

department_code
String

Code INSEE du département actuel (2A, 2B pour la Corse).

lat
Float

Latitude WGS 84 du lieu, en degrés décimaux ; nulle si le lieu est inconnu.

lng
Float

Longitude WGS 84 du lieu, en degrés décimaux ; nulle si le lieu est inconnu.

location_precision
String

D'où vient la position : exact (coordonnées données par la source), level_crossing (passage à niveau cité, jeu SNCF Réseau), station (gare ou lieu cité), commune (centre de la commune : lieu exact inconnu). Nulle si le lieu est inconnu.

deaths
Int

Nombre de morts, selon toll_source ; nul si inconnu (0 : aucun mort).

injuries
Int

Nombre de blessés ; nul si inconnu. Les sources comptent parfois différemment : voir review_status.

toll_source
String

Fournisseur du bilan retenu : bea-tt (enquête officielle, préférée), wikidata, wikipedia.

toll_source_url
String

Lien qui appuie le bilan retenu (référence Wikidata, permalien Wikipédia, rapport du BEA-TT).

summary
String!
Non-null

Résumé rédigé par VFF à partir des faits retenus, jamais recopié d'une source.

wikipedia_url
String

Article de Wikipédia sur l'accident dans la langue demandée, nul s'il n'existe pas.

review_status
String!
Non-null

ok : date et lieu confirmés par une source primaire (enquête du BEA-TT) ou par deux sources indépendantes (voir verification) ; to_review quand un point reste incertain (voir review_notes). Le rattachement à une ligne porte sa propre confiance.

verification
JSON

Vérification de la date et du lieu (vff:verify-accidents) : rule (primary_source, two_sources, wikidata_wikipedia, wikipedia_editions ou absente), date et place (valeur retenue ; sources qui concordent confirmed_by, qui divergent disagreeing, communes voisines nearby, chacune avec provider, role, url et la date de lecture retrieved_at), families, kind (nature lue dans une source), aliases (autres éléments Wikidata du même accident, gardés avec leurs sources). Nul si la fiche n'a pas été vérifiée.

verified_at
DateTime

Date de la dernière vérification, nulle si la fiche n'a pas été vérifiée.

provenance
JSON!
Non-null

Fournisseur de chaque fait retenu, comme provenance de GET /api/v1/accidents/{slug} : clés date, kind, location, deaths, injuries et name (vff : nom construit par VFF) ; kind vaut context quand la nature a été corrigée d'après les documents du contexte, label pour une nature tirée du seul nom. Objet vide si aucun fait n'est attribué.

imported_at
DateTime!
Non-null

Date du dernier import de la fiche (ISO 8601).

kind_label
String!
Non-null

Nature en toutes lettres (« Déraillement »), comme kind_label de l'API REST.

department_name
String

Nom du département actuel du lieu (« Hérault »), comme place.department de l'API REST ; nul si le département est inconnu.

review_notes
[AccidentReviewNote!]!
Non-null

Points incertains : bilans ou dates qui diffèrent selon les sources, lieu vague, ligne incertaine.

trains
[AccidentTrain!]!
Non-null

Trains et matériel impliqués, quand les sources les nomment.

lines
[AccidentLineLink!]!
Non-null

Lignes rattachées, avec la portion, le PK estimé, la méthode et la confiance (ordre non garanti : la principale a is_primary).

nearest_station
Station

Gare VFF la plus proche du lieu, ouverte à la date quand ses dates sont connues (10 km au plus).

nearest_station_distance_m
Int

Distance du lieu à nearest_station, en mètres.

sources
[AccidentSource!]!
Non-null

Sources consultées, avec leur licence et les faits lus dans chacune.

context
AccidentContext!
Non-null

Contexte sourcé (circonstances, déroulement, victimes, causes, suites, mémoire, contradictions entre sources), rédigé par VFF à partir de documents lus, avec ces documents, les images de Wikimedia Commons et les corrections faites d'après eux. Listes vides si la fiche n'a pas encore de contexte. Même contenu que context de GET /api/v1/accidents/{slug}.
