LineSheet
Object

Fiche complète d'une ligne : tout ce que montre la page /lines/{slug}, au même contrat que GET /api/v1/lines/{line}. Les parties très imbriquées (faits, phases, décennies, chronique, exploitations associatives, sources) sont des objets JSON dont chaque champ est décrit dans la documentation REST (/docs/api, « Fiche complète d'une ligne »).

Fields

#

slug
String !
Non-null

Slug de la ligne.

code
String

Code SNCF Réseau à 6 chiffres.

name
String !
Non-null

Nom usuel.

names
[LineName !]!
Non-null

Autres noms, chacun avec sa source.

wikidata
String

Élément Wikidata de la ligne.

network
String

Réseau : principal, secondaire, militaire, particulier.

is_lgv
Boolean !
Non-null

Ligne à grande vitesse (signalisation en cabine).

is_threatened
Boolean !
Non-null

Ligne menacée de fermeture.

description
String

Extrait de l'article Wikipédia, en français, sous CC BY-SA 4.0 (voir description_source).

description_source
LineDescriptionSource

Source de la description : auteur collectif, article, permalien de la révision lue et licence à citer.

historical_operator
String

Compagnie d'origine.

historical_operators
[LineOperator !]!
Non-null

Compagnies et gestionnaires successifs.

concession_year
Int

Année de concession.

regions
[String !]!
Non-null

Régions traversées (noms).

departements
[String !]!
Non-null

Départements traversés (noms).

wikipedia_title
String

Titre de l'article Wikipédia.

archeo_url
String

Article d'archeoferroviaire (usage non commercial, crédit et lien).

today
LineToday !
Non-null

État aujourd'hui.

key_figures
LineKeyFigures !
Non-null

Chiffres clés.

electrification
LineElectrification

Électrification à l'ère affichée, ou nul.

signalling
LineSheetSignalling !
Non-null

Signalisation à l'ère affichée.

facts
JSON

Faits de la fiche, chacun avec key, sa valeur (km, mm, kmh…), source, scope (line ou part), item, as_of, label et note en français.

era_summary
[LineEraSummary !]!
Non-null

État décennie par décennie.

portions
JSON

Tronçons élémentaires des phases : index, length_m et, avec geometry: true, geometry GeoJSON, geometry_withheld et geometry_withheld_reason. La géométrie d'une portion n'est jointe que si toutes ses sources autorisent la redistribution ; sinon elle vaut null, geometry_withheld vaut true et geometry_withheld_reason donne la raison (licence_not_open : source dont la licence n'autorise pas la redistribution ; unknown_source : source absente du registre des droits).

phases
JSON

Phases datées : date, precision, kind, changes (from, to, length_m, event_id), state par portion, length_by_category, active_m.

best_phase
Int

Indice de la phase où la ligne était la plus étendue.

phases_unexplained
JSON

Écarts entre la dernière décennie et les sources d'aujourd'hui qu'aucun événement ne date.

decades
JSON

Décennies : year, length_by_category (m), active_m, phases, stations (ouvertes, incertaines, fermées, fermetures).

chronicle
JSON

Chronique sourcée : events, groups (par portion), notes, conflicts, statuses.

stations
[LineSheetStation !]!
Non-null

Gares de la ligne, toutes ères, dans l'ordre du tracé.

sections
[LineSection !]!
Non-null

Sections nommées.

heritage
JSON

Exploitations associatives : name, operator, kind, from, to, length_km, periods, source_url.

materials
[LineSheetMaterial !]!
Non-null

Matériels roulants associés.

sources
JSON

Jeux de données utilisés pour la fiche : type, url, fetched_at, fields.

links
JSON

Liens : page web et points d'accès REST liés (événements, tronçons, gares, médias…).
